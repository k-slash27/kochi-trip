# Google マイマップ作成手順（高知旅行 2026）

`index.html` に埋め込む統合マイマップを作成するための最短手順です。所要時間の目安は10分です。

## 1. マイマップを新規作成

1. https://www.google.com/maps/d/ を開き、Googleアカウントでログイン
2. 「新しい地図を作成」をクリック
3. 左上の「無題の地図」をクリックし、名前を「高知旅行 2026（8/13–8/16）」に変更

## 2. 地点レイヤをCSVで取り込み（2レイヤ）

1. 「無題のレイヤ」の「インポート」をクリックし、`mymap/spots.csv` をアップロード
   - 目印を配置する列 →「住所」、マーカーのタイトル →「名称」を選択
   - レイヤ名を「空港・ホテル」に変更
2. 「レイヤを追加」→「インポート」で `mymap/restaurants.csv` をアップロード（同じ列指定）
   - レイヤ名を「レストラン」に変更
3. 位置がずれた地点があれば、マーカーをドラッグして修正

## 3. ルート4区間を追加（4レイヤ）

検索ボックス下の「ルートを追加」アイコン（矢印の分岐マーク）を使います。1回クリックするごとに1つのルートレイヤが作られます。

各レイヤで移動手段が「車」（自動車アイコン）になっていることを確認し、A・Bに以下を入力してください。

| レイヤ | A（出発地） | B（目的地） |
|---|---|---|
| DAY1 8/13 | 高知空港 | 高知パシフィックホテル |
| DAY2 8/14 | 高知パシフィックホテル | ホテル星羅四万十 |
| DAY3 8/15 | ホテル星羅四万十 | JRクレメントイン高知 |
| DAY4 8/16 | JRクレメントイン高知 | 高知空港 |

レイヤ名はそれぞれ「DAY1 空港→パシフィック」のように変更しておくと見やすくなります。

## 4. 共有設定（Webサイトから閲覧可能にする）

1. 「共有」をクリック
2. 「リンクを知っている全員が閲覧できるようにする」をオンにする
   （これをオンにしないと iframe 埋め込みが表示されません）

## 5. 埋め込みURLを取得

1. 地図名の右の「⋮」メニュー →「自分のサイトに埋め込む」をクリック
2. 表示される iframe コードの `src` （`https://www.google.com/maps/d/embed?mid=～` 形式）をコピー
3. その URL を伝えてください。`index.html` の「旅のマップ」セクションの iframe に反映します
   - 併せて共有URL（`https://www.google.com/maps/d/edit?mid=～` または viewer URL）も共有してください
